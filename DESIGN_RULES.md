# DESIGN RULES

## Mood

Quiet lake at dawn.

The design should feel like a calm real place,
not a decorative fantasy scene.

## Visual Keywords

- quiet
- realistic
- restrained
- spacious
- natural
- atmospheric
- elegant
- minimal

## Color Direction

Use dark lake and dawn-inspired colors.

Recommended base colors:

- Deep lake: #07131A
- Dark blue green: #0D1B22
- Forest shadow: #11242C
- Mist text: #F4F1EA
- Soft gray text: #D7D7D7
- Muted blue accent: #8EA7B2

Avoid:

- bright neon
- oversaturated green
- purple cyberpunk gradients
- colorful startup-style gradients

## Typography

Typography should be simple, elegant, and readable.

Use large negative space.
Use clear hierarchy.

Hero title should feel quiet and confident.

Main Korean copy:

앞으로 갑니다, 한 걸음씩

Supporting copy should be short.

## Layout

The site is one-page scroll based.

Each section should feel like a complete scene.

Text must never be hidden by visual elements.
Visual effects must support the content, not overpower it.

## Portfolio Function

The site must include:

- Hero / intro
- About
- Skills
- Projects
- Contact

The portfolio should look emotional,
but it must still be practical for recruiters and viewers.

## Emotional Flow

The portfolio must feel like one continuous emotional weather transition:

rain and dark lake
→ cloudy muted atmosphere
→ slightly brighter project area
→ warm sunlight with soft rainbow haze.

Do not make sections feel like separate templates.

The entire portfolio should feel like one connected atmosphere and emotional journey.
